Foundations (pages 01–02)

1. Which statement about the relationship between terms is correct?
AI ⊃ ML ⊃ DL ⊃ GenAI ⊃ LLMs. See page 01.
2. How are LLMs primarily pre-trained?
Self-supervised next-token prediction allows training on trillions of tokens without manual labels. Post-training (SFT, preference/RL) comes after.
3. Roughly how many English words fit in 1,000 tokens?
Rule of thumb: 1 token ≈ 4 characters ≈ ¾ of a word in English. Code often uses more tokens.
4. You want deterministic-ish, focused output for code generation. Which setting?
Low temperature makes the model pick high-probability tokens. Even at 0, outputs may vary slightly, so always validate.
5. Why do LLMs hallucinate?
Plausible text is not necessarily true text. Ground with docs and tools, and verify.
6. Your chat assistant "remembers" your preference for Scala 3 in a new chat. What is most likely happening?
Models are stateless between calls. "Memory" is context engineering by the product.

Prompting & context (pages 03–04)

7. Which is NOT one of the six prompt building blocks?
Role, task, context, constraints, format, examples. Calm, precise instructions beat emotional pressure.
8. Giving the model 3 input→output examples to copy a format is called…
Few-shot examples steer format and style without changing model weights.
9. A long chat keeps repeating the same wrong fix. Best move?
The polluted context keeps steering the model wrong. A clean context plus the lessons learned usually fixes it.
10. Which are the four moves of context engineering?
Write durable context, select relevant context, compress long context, isolate unrelated work. See page 04.
11. Why is a Scala type signature valuable context?
Types are dense, precise specs, and the compiler provides immediate feedback.

Tools, IDEs & customisation (pages 05–07)

12. Which IDE mode suits "add an endpoint with service, repository and tests, and make the build pass"?
Multi-file changes plus running the build and tests is agent work. Plan first.
13. What do VS Code, JetBrains IDEs and Xcode increasingly have in common?
For example, Xcode exposes build/test/docs tools via MCP, and Metals exposes Scala compiler tools via MCP.
14. What belongs in AGENTS.md?
Keep it concrete and short. No secrets. Move long procedures into skills.
15. In Agent Skills, what decides whether a skill gets loaded automatically?
With progressive disclosure, only name + description are visible up front, so the description must say what the skill does and when to use it.
16. You need code to be formatted after every agent edit, no exceptions. Use…
Instructions are requests. Hooks are deterministic guarantees.

Agents & MCP (pages 08–09)

17. In tool calling, who actually executes the tool?
The model emits a structured call. The host executes it and returns the result into context. The host is the security boundary.
18. An agent "fixes" a failing test by changing the expected value. This is…
Instruct "don't modify tests without asking" and review test diffs carefully.
19. Which problem does MCP mainly solve?
One server works with every MCP-capable host: N+M instead of N×M.
20. Which three are MCP server primitives?
Sampling, elicitation and roots are client features that servers can request.
21. A local MCP server launched by your IDE as a child process typically uses which transport?
stdio for local processes. Streamable HTTP for remote servers.

Scala, Python, IT, learning, safety (pages 10–14)

22. Which is a common AI mistake in Scala code?
State the Scala version and conventions in AGENTS.md, and keep the compiler in the loop.
23. An AI suggests installing a Python package you have never heard of. What should you do first?
Attackers register package names that models commonly hallucinate.
24. Which learning approach builds real skill?
Active recall, Feynman, deliberate practice and spacing. See page 13.
25. Which combination makes prompt-injection data theft most likely?
The "lethal trifecta". Remove at least one leg, and keep approvals on for outbound or destructive tools.
