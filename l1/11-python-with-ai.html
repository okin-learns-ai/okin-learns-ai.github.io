11 · Python Development with AI

Python is the native language of the AI ecosystem. Nearly every model SDK, framework and research codebase ships Python first. Models are also very fluent in it. This page shows how to get high-quality Python from AI and avoid its typical traps.

Why Python matters for AI work, even for Scala developers

  • Most AI tooling (MCP servers, evals, notebooks, data science, fine-tuning) is easiest in Python.
  • Prototype AI features in Python and productionise them in Scala/JVM if your platform requires it.
  • Models generate excellent Python, which makes it a fast way to automate chores: scripts, data checks, log analysis.

Prompting for good Python

  • State the version: "Python 3.12" lets the model use modern syntax (match, X | None, built-in generics like list[int]).
  • Ask for types and docstrings: "Fully type-annotated, mypy --strict clean, Google-style docstrings."
  • Name the libraries and versions: "pydantic v2", "pandas 2.x", "httpx not requests", "SQLAlchemy 2.0 style".
  • Request structure: "Pure functions in core, I/O at the edges, dataclasses for data."
  • Ask for tests in the same answer: "Then pytest tests with parametrize for edge cases."

Tests as the safety net

import re
import pytest
from hypothesis import given, strategies as st

def slugify(title: str) -> str:
    """Lowercase, keep a-z0-9, collapse everything else into single hyphens."""
    return re.sub(r"[^a-z0-9]+", "-", title.lower()).strip("-")

@pytest.mark.parametrize("raw, expected", [
    ("Hello World", "hello-world"),
    ("  Scala 3 & Python!  ", "scala-3-python"),
    ("---", ""),
    ("", ""),
])
def test_examples(raw: str, expected: str) -> None:
    assert slugify(raw) == expected

@given(st.text())
def test_properties(raw: str) -> None:
    s = slugify(raw)
    assert s == slugify(s)                      # idempotent
    assert not s.startswith("-") and not s.endswith("-")
    assert "--" not in s
    assert re.fullmatch(r"[a-z0-9-]*", s)

uv run pytest -q test_slugify.py

Hypothesis generates hundreds of random inputs, including Unicode, and checks the properties. This kind of test catches the edge cases AI-written code most often misses.

Your first LLM call from Python

Standard library only, against a local OpenAI-compatible server (Ollama). For hosted providers, use their official SDK and an API key from an environment variable.

import json
import os
import sys
import urllib.request

ENDPOINT = os.environ.get("LLM_ENDPOINT", "http://localhost:11434/v1/chat/completions")
MODEL = os.environ.get("LLM_MODEL", "llama3.2")


def ask(question: str) -> str:
    payload = {
        "model": MODEL,
        "temperature": 0.2,
        "messages": [
            {"role": "system", "content": "You are a concise Python expert."},
            {"role": "user", "content": question},
        ],
    }
    headers = {"Content-Type": "application/json"}
    if key := os.environ.get("LLM_API_KEY"):          # hosted providers
        headers["Authorization"] = f"Bearer {key}"
    req = urllib.request.Request(ENDPOINT, data=json.dumps(payload).encode(), headers=headers)
    with urllib.request.urlopen(req, timeout=120) as resp:
        data = json.load(resp)
    return data["choices"][0]["message"]["content"]


if __name__ == "__main__":
    print(ask(" ".join(sys.argv[1:]) or "Explain Python decorators in 3 sentences."))

Compare it with the Scala version on page 10. The request shape is identical. That is the value of a common API shape.

Everyday Python + AI wins

  • Throwaway automation: "Write a script that reads all *.log files, extracts ERROR lines with timestamps, and outputs a CSV summary per hour." Review it, run it, delete it.
  • Data exploration: in a notebook, ask the assistant to load a CSV, profile it, and suggest data-quality checks.
  • Glue code: converting formats (JSON ↔ YAML ↔ CSV), calling REST APIs, generating test fixtures.
  • Learning: "I know Scala. Explain Python's iterators/generators by comparing them to Scala's Iterator and LazyList."

Key takeaways

  • Python is the lingua franca of AI tooling, so it is worth knowing even if your main language is Scala.
  • uv + ruff + mypy + pytest/hypothesis give agents fast, automatic feedback.
  • State version, typing level and library versions. Watch for the classic Python and security mistakes.
  • Verify unfamiliar packages before installing. Hallucinated packages are an attack vector.
