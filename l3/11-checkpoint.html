MCP servers & agents (pages 01–02)

1. In MCP, the host learns what a server offers by…
Capability discovery is part of the protocol. See page 01.
2. With FastMCP, a tool's input schema comes from…
Write type hints and docstrings as contracts — they become the schema the model sees.
3. On a stdio MCP server, where should logs go?
One stray print on stdout corrupts the JSON-RPC stream.
4. An agent's memory strategy should…
See page 02.
5. A tool throws an exception. The agent should…
Models recover well from errors fed back as results. Three repeats = stuck.
6. Which is NOT a required stopping condition?
Temperature steers the model; limits guarantee the loop ends.

Multi-agent & evals (pages 03–04)

7. Multi-agent systems are justified mainly when…
See page 03.
8. Agents should communicate via…
Artefacts keep contexts clean and results verifiable.
9. Three pipeline stages at 90% accuracy each give roughly…
0.9³ ≈ 0.73. Errors compound multiplicatively — check between stages.
10. The best use of an LLM-as-judge is…
See page 04.
11. Agent evals should grade…
A right answer reached via 15 wasted calls or a security violation is still a failure.
12. A golden dataset should NOT…
Tuning on the test set = overfitting the test. Keep a held-out slice.

RAG & fine-tuning (pages 05–06)

13. Users search exact codes like "ORD-482913" and vector search misses them. Fix?
See page 05.
14. A re-ranker improves precision by…
Cheap recall (fetch ~50), expensive precision (re-rank to ~5).
15. When does a knowledge graph (GraphRAG) beat chunks?
Graphs earn their build cost on relational questions, not FAQs.
16. Fine-tune for…
Knowledge goes in RAG; behaviour goes in fine-tuning. See page 06.
17. LoRA works by…
~1% of params trained; QLoRA does it on a quantised base to save memory.
