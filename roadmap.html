Curriculum Roadmap: Beginner to Expert

The full map: 5 levels × 20 tracks, plus specialist electives. Use it to see where you are, what comes next, and what "expert" actually means in each area.

All levels15 minLast updated 2026-10-08

How the curriculum is designed

Expertise in AI is not one skill. It is a stack of skills, from using tools well, to building with models, to understanding what happens inside them. The curriculum is organised in two dimensions:

  • Levels (vertical): how deep you go. Every level has the same structure: concepts, practice, labs, checkpoint.
  • Tracks (horizontal): the subject area. Each track runs through all five levels, so you can see how a topic grows from "what is it" to "I can design and teach this".

Level 3: Advanced (available)

Goal: design and build robust AI systems: agents, tool servers, evaluation, deployment and security.

  1. Building MCP servers in Python (official SDK) and on the JVM (Java SDK used from Scala): tools, resources, prompts, auth, testing with an inspector.
  2. Building agents from scratch: the loop, tool schemas, state, memory, error recovery, stopping conditions. Then frameworks and when to avoid them.
  3. Multi-agent systems: orchestrator-worker, planner-executor, critics, handoffs, agent-to-agent protocols (A2A, ACP).
  4. Evals: golden datasets, rubric grading, LLM-as-judge pitfalls, agent trajectory evaluation, regression suites in CI.
  5. Advanced RAG: hybrid BM25 + vector, re-rankers, query rewriting, GraphRAG, agentic retrieval.
  6. Fine-tuning: LoRA/QLoRA, dataset building, overfitting, distillation, quantisation, evaluation before/after.
  7. LLMOps: tracing, observability, caching, model routing, cost dashboards, guardrails, rate limiting.
  8. AI security: prompt injection (direct/indirect), data exfiltration, tool poisoning, sandboxing, OWASP Top 10 for LLM apps, red-teaming.
  9. Level 3 Labs: eight hands-on labs, one per page.
  10. Capstone: a production agent with a custom MCP server, an eval suite, observability and a security review.
  11. Level 3 Checkpoint Quiz: 20 questions across the level.

Level 4: Expert (available)

Goal: understand the machinery: how models are built, trained and served, and make architecture-level decisions.

  1. The maths you actually need: vectors, matrices, gradients, softmax, cross-entropy, probability — all in runnable code.
  2. Transformer internals: attention from scratch, multi-head, layer norm, residuals, positional encodings, a tiny GPT.
  3. Training and post-training: pre-training data, SFT, RLHF, DPO, RLVR, constitutional approaches.
  4. Inference optimisation: KV cache, batching, paged attention, speculative decoding, quantisation, serving engines.
  5. Reasoning models and test-time compute: CoT, self-consistency, verifiers, effort dials, when "thinking" helps.
  6. AI-native architecture: the gateway pattern, build vs buy, platform teams, cost/reliability.
  7. Governance: EU AI Act risk tiers, model risk management, documentation, paved paths.
  8. Level 4 Labs: seven labs — implement attention, train a tiny GPT, benchmark serving.
  9. Capstone: mini-GPT trained, quantised, served, benchmarked, plus a design document.
  10. Level 4 Checkpoint Quiz: 20 questions across the level.

Level 5: Master & Specialist (Phase 5, planned)

Goal: push the frontier in a chosen speciality and multiply others.

  • Research skills: how to read a paper in three passes, reproduce results, run ablations, write up findings.
  • Interpretability and alignment: probing, sparse autoencoders, circuits, reward hacking, scalable oversight.
  • On-device AI: Apple silicon, Core ML, MLX, on-device foundation models, privacy-preserving design.
  • Multimodal: vision-language models, speech (ASR/TTS), diffusion, video, robotics foundation models.
  • Leadership: AI adoption playbooks, measuring productivity honestly, training teams, policy writing.
  • Capstones: choose a speciality project and publish it (blog, talk, open-source, paper).

Specialist electives (niche but valuable)

These go deep on narrow topics. Pick them up whenever you meet them at work.

Functional programming & AI

Typed effect systems (Cats Effect, ZIO) for agent orchestration; why strong types make AI code safer.

Text-to-SQL & semantic layers

Getting correct SQL from natural language. Schema grounding and validation.

Code search & code intelligence

LSP, symbol graphs, tree-sitter, embeddings for code. How IDE agents "see" your repo.

Synthetic data

Generating test data, eval sets and training data, and how to avoid model collapse.

Structured generation

Constrained decoding, grammars, JSON-mode internals.

AI for legacy modernisation

Migrating Java to Scala 3, Scala 2 to 3, monolith to services, with agents and tests as a safety net.

Accessibility & AI

Using AI to build accessible UIs, and AI as an assistive technology.

Edge & embedded AI

TinyML, quantised models on devices, latency budgets.

AI for documentation

Docs-as-code, keeping docs in sync with code, generating diagrams.

Recommender systems

Classic and LLM-era recommendation, ranking, embeddings at scale.

Time-series & forecasting

Classical methods, foundation models for time series.

AI economics

Token pricing, cost per task, latency vs quality vs cost trade-offs.
